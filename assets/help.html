Rufus Portable

Rufus creates bootable USB media. This is a community-prepared portable package based on the official Rufus application.

Getting started

Launch RufusPortable.exe from the RufusPortable folder. Rufus may require administrator access to work with USB drives.

Only select a USB drive you intend to erase. Creating bootable media can overwrite the selected drive and permanently remove its files.

Your settings and upgrades

Keep the complete RufusPortable folder together when moving it. Preserve its Data folder when upgrading to a newer package. Close Rufus before installing an update.
